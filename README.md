
# Marketplace Seller Performance Pipeline

An end-to-end data engineering project for processing
marketplace data, storing it in MySQL, and exposing
seller performance insights through APIs.

## Objectives

- Ingest and validate source data.
- Clean and transform data using Python and Pandas.
- Store processed data in MySQL.
- Build API endpoints using FastAPI.
- Test data quality and application behavior.
- Document implementation decisions and results.

## Tech Stack

- Python
- Pandas
- MySQL
- SQLAlchemy
- PyMySQL
- FastAPI
- Uvicorn
- Git and GitHub

## Repository Structure

- `src/` - Application and pipeline code
- `sql/` - Database schema and SQL queries
- `tests/` - Automated tests
- `docs/` - Technical documentation
- `data/` - Input and processed data
- `screenshots/` - Selected project evidence
